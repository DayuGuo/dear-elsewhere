# 树下拆信 · 设计复核

用同一组模拟来信逐版对照。旧版在 1360px 窗口中，短邀请的信纸比长邀请短 36.7px。最终版的三张信纸底边都在 599.48px，三条选择链接的底边都在 572.09px。

第一版对齐信纸和选择链接，以三枚植物邮票替换重复的大幅信封。第二版调大日期数字、压短信头，并记住已拆的信。第三版修正混合开合时的点击空白，加上细封口折线，再从排版开始检查全部八项。

| 项目 | 设计取舍及末轮检查 |
| --- | --- |
| 排版 | 英文采用 Cormorant Garamond，中文采用思源宋体。日期用 Georgia 数字搭配宋体，使月份与日数在小字号也易辨认。中英文长短邀请均可完整换行。 |
| 留白 | 展开后，桌面信头收短，让信文紧接日期和邮票。三封信共用底线，短文多出的留白落在文字与选择链接之间。 |
| 视觉层次 | 一行拆信说明之后直接读信。页首可换一组，信头控制开合，信底才出现选择入口。模拟数据说明移至页脚。 |
| 色彩 | 暖白纸底、深墨色正文、橄榄绿操作文字，蔷薇粉留给邮票。相对页面底色，正文、次要文字、操作文字的对比度分别约为 12.65∶1、5.87∶1、6.73∶1。 |
| 动效 | 信纸展开用 220 毫秒，开合符号用 200 毫秒。启用系统减少动态效果后，正文立即出现，邮票无过渡。 |
| 微交互 | 整封未拆的信可点，包括邻信展开时增高的区域。键盘可展开、收起、选择。刷新或切换语言后保留同组来信和展开状态。 |
| 响应式 | 在 320、390、740、768、1024、1360px 检查了两种语言和全部八种开合组合。740px 及以下为单列，高于此宽度同排信底和已显示的选择链接对齐。受测布局均无横向溢出。 |
| 原创性 | 蔷薇花、蔷薇果和蝴蝶均取自本项目挂信树插画。首页在树上取信、拆信页辨认邮票、详情页沿枝读回信，三个动作使用同一套图像。 |

## 参照作品

- 《Miranda – Paper Portfolio》以报纸版式组织屏幕内容。这里借鉴其纸面阅读秩序，用日期、邮票和信文构成一封可读的信。[Awwwards 获奖页](https://www.awwwards.com/sites/miranda-paper-portfolio)
- 《The Book of HOV》以章节组织展览。这里对照它的导航层次，把换一组、拆信和选信分配在三个明确的位置。[Webby 获奖页](https://winners.webbyawards.com/2024/websites-and-mobile-sites/general-desktop-mobile-sites/cultural-institutions/289534/the-book-of-hov)
- 《Paper Planes》用投出与接住纸飞机连接参与者。这里对照它让物件本身成为操作入口的做法，让整封信都能拆开。[Active Theory 项目及 FWA 获奖记录](https://lbbonline.com/work/153553)

## 验证范围

本机 Chromium 与 WebKit 各检查了 96 组布局状态，并另测键盘操作、切换语言、刷新和减少动态效果。用高度增至 480px 的中间信文模拟外部嵌入重新排版，左右信纸和操作入口随之对齐。上述页面使用模拟数据，真实 X 嵌入仍待线上验证。末轮在这个范围内未发现新的排版或交互缺陷。
